최신 NiceGUI 대시보드 프로젝트 — 2026-11-25 수정본

실행
1. ZIP 전체를 압축 해제합니다.
2. Windows용 Python 3.12를 설치한 뒤 Install-Dependencies.cmd를 처음 한 번 실행합니다.
3. Open-Shared-Dashboard.cmd를 실행합니다. 주소는 http://127.0.0.1:8092/regions 입니다.
   같은 PC에서 이전 대시보드가 이미 실행 중이면 이전 창이 열릴 수 있습니다.
   별도 포트 확인: .venv\Scripts\python.exe -B -m nicegui_dashboard app --port 8196
   이후 http://127.0.0.1:8196/regions 에 접속합니다.

이번에 포함한 최신 코드
- 시연 대상 50지역 선정, 카드·필터·전체 실행 범위와 제외 근거.
- Transformer·LightGBM·물리 통신 판단을 구분한 현재 모델 설명.
- 지역별 제어 4개와 예측 4개 지표(AP·중계기 이동거리 포함).
- 실제 역할, 고도와 운용 단계 표시, 특수 중계 역할의 진한 파랑 표시.
- 전체 통신·확률 패널 우선 배치 및 카드의 ‘적용 모델’ 문구.
- 다음 계산 때 운용 기록과 평가를 함께 수집하는 연결 코드.
- 빠른 비행 방식·지역 선택의 전달을 안정화한 최신 소스.

실제 결과 데이터 범위
이전 프로젝트 ZIP과 같은 방식으로 분당의 실제 적용·미적용 비행 한 세트를 넣었습니다.
분당의 최신 운용·고도 기록, 제어 집계, AP 포함 별도 기준 비행 평가도 함께 들어 있습니다.
분당 적용 비행: CTR 99.13%, PDR 99.69%, 새 지속 단절 3회, 누적 12.5초.
나머지 지역은 포함된 과거 공유본의 비행을 기반으로 표시합니다.
50개 지역의 최신 계산 결과 전체를 복제한 백업은 아닙니다.
‘선행탐지율’과 AP는 별도 평가용 기준 비행의 성능이며 재생 비행의 단절 횟수와 다릅니다.

포함/제외
최신 소스(새로 추가된 파일 포함), requirements.txt, 실행 스크립트,
상대 경로 설정, 기존 화면 기반 자료, 분당 실제 결과와 보강 파일을 포함했습니다.
가상환경, Git 인증·이력, 작업 로그, 임시 캐시, 다른 지역 최신 대용량 결과는 제외했습니다.
원본 연구 코드·모델·비행 결과는 변경하지 않았고 새 시뮬레이션도 실행하지 않았습니다.

새 계산
저장 결과 재생과 분석은 이 ZIP으로 가능합니다.
팀 코드 갱신 및 새 시뮬레이션에는 별도의 팀 저장소, 연구 실행 환경,
지도·모델 자료를 연결해야 합니다. 자세한 연결 방법은 README.md를 참고하세요.
data의 HTML은 화면 기반 자료이며, 직접 열면 과거 공유본입니다.
NiceGUI는 위 실행 스크립트로 여세요.

검증
SOURCE_SNAPSHOT.json은 현재 수정 상태와 파일별 SHA-256을 기록합니다.
PACKAGING_VERIFICATION.txt에 이 ZIP 자체의 확인 범위를 남겼습니다.
